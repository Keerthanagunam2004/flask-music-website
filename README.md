# Moodify – Mood Based Music & Quote Recommender 🎧🌈

Moodify is a Flask web application that recommends music and motivational quotes based on the user's current mood.

## Features
- Multi-page Flask application
- Mood selection with interactive cards
- Music and quote recommendations
- Clean and attractive UI using HTML & CSS
- Template inheritance using Flask (base.html)

## Technologies Used
- Python
- Flask
- HTML
- CSS
